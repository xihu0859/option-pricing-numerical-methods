# 期权定价：Monte Carlo 与有限差分数值方法

[English README](README.md) · [完整报告](docs/report.pdf) · [定价程序](reproduce.py) · [桌面应用](app.py)

## 项目目标

比较数字期权、连续监测上敲出期权和算术平均亚式期权的定价方法，区分模拟抽样误差、障碍监测偏差与
有限差分网格误差，并判断精度提升是否值得额外计算成本。这是个人项目，独立于养老金资产配置团队项目。

## 数据与方法

不使用历史市场数据。股价路径由风险中性几何布朗运动生成，初始价格 100、利率 5%、波动率 25%、期限一年。
实现标准 Monte Carlo、对偶变量、重要性抽样、Brownian bridge、几何平均控制变量，以及显式／隐式 Euler、
Crank--Nicolson 和 Rannacher 启动的有限差分求解；提供图形界面比较结果并导出 CSV。

## 主要发现

- 数字期权的重要性抽样在等量收益计算预算下，将方差降低约 5.28 倍。
- 障碍期权只检查离散日期会漏掉期间越界，增加模拟路径不能消除这种偏差；桥接条件概率可以在本模型下修正。
- 亚式期权在一百万条生产路径下，几何控制变量降低方差约 835 倍；计入独立 pilot 成本后的方差与时间乘积
  改善约 675 倍。独立两百万路径验证与原估计在一个合并标准误内一致。

## 查看与复现

英文 README 包含环境、运行命令、目录和限制。执行 `python verify.py` 做数学及程序检查，
`python app.py` 打开桌面应用，`python reproduce.py` 重现实验。
`data/` 是模型生成的汇总实验结果，可以直接查看；报告及源文件在 `docs/`。

方差缩减倍数和用时来自特定实验，不能理解为对所有市场或所有运行环境的保证。
